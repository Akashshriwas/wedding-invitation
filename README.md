# Pranjal & Prekshi — Wedding Invitation

A single-page digital wedding invitation for **Pranjal Saxena & Prekshi Saxena**,
25 November 2026, Ghaziabad.

**Live site:** https://akashshriwas.github.io/wedding-invitation/

## What's inside

| Path | What it is |
|---|---|
| `index.html` | The entire site — markup, styles and scripts in one file |
| `images/` | Photographs and the gold "प्र" seal logo |
| `music/` | Drop a `theme.mp3` here for background music (optional) |

## Features

- Gold-seal opening curtain that parts on tap
- Parallax photo backgrounds with gold-leaf framing
- Scratch cards revealing each event's date and venue
- Live countdown to the wedding day
- Names in both English and Devanagari
- Works on phones, tablets and desktop

## Background music

Music is optional. To add it, place a file at `music/theme.mp3`. It starts when a
guest taps the gold seal (browsers block autoplay until a visitor interacts) and
the round button at the bottom-right toggles it. Without the file the site works
exactly the same — the music button simply fades away.

## Editing

Everything lives in `index.html`. Edit it, commit, and push to `main`; GitHub
Pages redeploys the site automatically within a minute or two.
